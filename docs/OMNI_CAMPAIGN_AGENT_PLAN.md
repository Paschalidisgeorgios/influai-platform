# InfluExAi — Omni Campaign Agent Plan

**Document type:** Product/engineering plan  
**Status:** Planned (disabled)  
**Scope:** No runtime provider calls in current release

## Goal

Turn one campaign idea into a guided multi-asset plan across formats:

- visuals
- video concepts
- captions
- hashtags
- export-ready checklist

## Future flow

1. Campaign idea
2. Target platform
3. Niche / product
4. Style profile
5. Output plan:
   - feed posts
   - story visuals
   - reel/video concepts
   - captions
   - hashtags
   - export checklist

## Safety and cost controls

- No automatic expensive provider calls without explicit user confirmation.
- Show estimated credits before generation.
- User selects exact assets before provider calls.
- Keep Standard Image fallback for each selected asset.

## Current release behavior

- Omni Campaign Agent appears only as roadmap/planned UI.
- No API route, no worker integration, no credit debit path.
